# $bog_pair

Стенд проверки: соединятся ли два браузера в одной сети без интернета и без сервера.

https://b-on-g.github.io/pair/

1. Открыть страницу на обоих устройствах, пока есть интернет (дальше она работает офлайн).
2. Отключить интернет, оставить общую сеть: роутер или раздачу с телефона.
3. Первое устройство: «Пригласить», разрешить камеру, показать QR.
4. Второе: «Сканировать QR», навести на код, показать свой ответный QR.
5. Первое: «Сканировать QR» на ответ.
6. Статус покажет маршрут, например `host udp 192.168.0.5 ⇄ host udp 192.168.0.7`, и можно переписываться.

Вместо QR можно скопировать код и вставить его в поле. На Android в Chrome можно передать код через NFC-метку (NTAG216): записать приглашение, второе устройство читает и записывает ответ.

Камеру страница просит даже без сканирования: без этого разрешения браузер показывает только основной сетевой адрес и прячет его за `.local`-именем.
